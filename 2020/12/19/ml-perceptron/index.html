Algorithm

  1. $\alphab \leftarrow 0, b \leftarrow 0$ ($\alphab = (\alpha_1, \alpha_2, \ldots, \alpha_N)$)
  2. Select a data point $(\xb_i, y_i)$ from the training set
  3. If $y_i \left(\sum_{j=1}^N \alpha_j y_j \color{red}{ \xb_j \cdot \xb_i} + b\right) \leq 0$, update the $\alpha_i$ and bias $b$ by
  4. Go back to step 2, until no misclassified data.
