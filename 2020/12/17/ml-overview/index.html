Overview

The three elements of statistical learning

Model + Strategy + Algorithm

MODEL

  • Hypothesis space
    • A set of deterministic funtions
    • A set of conditional probabilities
  • Generative Model and Discriminative Model
    • Generative Model
      • Explicitly models the actual distribution of each class, i.e. the joint distribution $P(X, Y)$.
      • $P(Y\mid X) = P(X, Y) / P(X)$
      • Examples: Naive Bayes, Hidden Markov Model
    • Discriminative Model
      • Models the decision boundary between the classes.
      • Estimate parameters of $P(Y\mid X)$ directly from training data
      • Examples: KNN, Perception Machine, Decision Tree, Logistic Regression, Maximum Entropy Model

STRATEGY
How to choose the best model?

  • Loss function
    smaller loss function value => better model
    • 0-1 loss function
    • quadratic loss function
    • absolute loss function
    • logarithmic (log-likelihood) loss function

  • Risk function
    Risk function or expected loss.

    The target of machine learning is to select the model that minimizes the risk function. However, we do not know the exact distribution of $P(X, Y)$, such that $R_{exp}$ cannot be computed directly and supervised learning becomes an ill-formed problem.

    Empirical risk or empirical loss.

    The empirical risk is introduced to approximate the risk function $R_{exp}$. When sample size $N$ approaches infinity, according to the large number theorem, $R_{emp} \rightarrow R_{exp}$.

    Structural risk

    If the training set is small, minimization of the empirical risk may lead to ‘overfitting’. To avoid this, a penalty term $\lambda J(f)$ is added to the empirical risk. Typically, the penalty term $J(f)$ is chosen so that it has a smaller value if the model is simpler. $\lambda \geq 0$ is a coefficient that balance the empirical risk and model complexity.

  • Methods
    • Empirical risk minimization [large enough dataset]
    • Structual risk minimization [regularization]At times when the model begins to underfit or overfit, regularization becomes necessary. It is a regression that diverts or regularizes the coefficient estimates towards zero. It reduces flexibility and discourages learning in a model to avoid the risk of overfitting. The model complexity is reduced and it becomes better at predicting.

The statistical learning problem becomes an optimization problem.

Supervised Learning Problems

Classification

  • Binary Classification or Multi Classification
    • $y_i \in \{0, 1\}$
    • $y_i \in \{0, 1, \ldots, k\}$
  • Confusion Matrix
    • TP, FM, FP, TN
    • [True/False] Predicted correctly or incorrectly
    • [Positive/Negative] The result of the classifier
  • Metric
    • Accuracy
    • Precision
    • Recall
    • $F_1$
      • Harmonic mean of precision $P$ and recall $R$
      • $F_1 \rightarrow 1$, results tending to be the best.
      • $F_1 \rightarrow 0$, results tending to be the worst.
      • Use it in classification tests where true negatives don’t matter much.

Tagging

  • A generalization of the classification problem
  • Input: a sequence of observations, i.e. a training set $T$ is a set of sequences $\{(x_1, y_1), (x_2, y_2), \ldots, (x_N, y_N) \}$, where $x_i = (x_i^1, x_i^2, \ldots, x_i^n), y_i = (y_i^1, y_i^2, \ldots, y_i^n)$ are two obseravation sequences. Typically, $n \ll N$.
  • Goal: Searching for a sequence $y$ for a given sequence $x$, that maximizes the conditional probability $\hat{P}(Y\mid X)$.
  • Examples: Conditional Random Fields, HMM

Regression

  • Statistical processes for estimating the relationships between a dependent variable and one or more independent variables (features).
  • Training data: $x_i \in \mathbb{R}^n$, $y_i \in \mathbb{R}$.
